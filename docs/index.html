Oracle Cloud Always Free

Fix "Out of host capacity" and get a free ARM VPS on Oracle Cloud

Oracle's Always Free tier gives you an Ampere A1 ARM server with up to 4 OCPU and 24 GB RAM, but the console usually answers "Out of host capacity". This open-source launcher retries for you every minute until Oracle has room, then notifies you. It works on Windows, Linux and macOS.

What it does

Retries automatically

Keeps asking for capacity, rotating availability domains, until the instance exists.

Never leaves Always Free

Refuses any request above the free limits: OCPU, RAM, 2 micros, 200 GB storage.

Setup wizard

Creates the API key, SSH key, oci_config and oci.env for you.

Notifies you

Desktop pop-up, plus optional Telegram, Discord or Gmail.

Start small, grow later

Get 2 OCPU / 12 GB first, then resize to 4 / 24.

Creates the network

Uses a public subnet, or builds VCN, gateway, route and subnet (free).

Quick start

You need an Oracle Cloud account and Python 3.12 (3.11 and 3.13 also work).

Windows

powershell -ExecutionPolicy Bypass -File setup_windows.ps1
powershell -ExecutionPolicy Bypass -File start_windows.ps1

Linux / macOS

git clone https://github.com/leandromarin18/oci-out-of-host-capacity-fix
cd oci-out-of-host-capacity-fix
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python setup_wizard.py
python main.py check
nohup python main.py > python_error.log 2>&1 &

FAQ

How do I fix "Out of host capacity" on Oracle Cloud Free Tier?

You can't fix it on Oracle's side: the region has no free A1 capacity right now. The workaround is to keep retrying until a slot opens, which is what this launcher does. Asking for 2 OCPU / 12 GB first usually gets you a server sooner.

Is it really free?

Yes, within the Always Free allowance: 3,000 OCPU-hours and 18,000 GB-hours of A1 per month (exactly 4 OCPU / 24 GB running 24/7) plus 200 GB of block storage. Oracle's cost estimator shows a price because it does not subtract the free allowance.

How long does it take?

It depends on the region. In busy regions it can take hours or days, so the computer running the launcher must stay on.
